# Windows Threat Hunting Lab Report

## Objective

Build a threat hunting lab using Splunk and Windows Event Logs.

## Tools Used

- Splunk Enterprise
- Splunk Universal Forwarder
- Windows
- Kali Linux

## Attack Simulations

- net user
- net localgroup administrators
- systeminfo
- Failed Login Attempts
- User Creation
- User Deletion

## Detections

- Event ID 4624
- Event ID 4625
- Event ID 4720
- Event ID 4726
- Event ID 4732
- Event ID 7045

## Conclusion

Successfully detected suspicious Windows activities using Splunk.
